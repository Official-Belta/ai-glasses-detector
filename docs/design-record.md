# 설계와 검증 기록

이 문서는 앱이 무엇을 처리하고 무엇을 처리하지 않는지, 그렇게 정한 이유와 검증한 방법을 날짜와 함께 남긴다.
코드나 동작을 바꾸면 이 문서도 같이 고친다. 마지막 갱신: 2026-10-25 (앱 1.0.0 출시 준비).

## 1. 읽는 것과 읽지 않는 것

앱은 주변 기기가 누구나 받을 수 있도록 공개 방송하는 블루투스 저전력(BLE) 광고 신호만 받는다.

읽는 것 (광고 신호의 메타데이터)
- 제조사 ID: 제조사 데이터의 앞 2바이트. Bluetooth SIG가 공개 배정한 번호다. `app/lib/src/model/advertisement.dart`
- 서비스 UUID, 서비스 데이터의 UUID 키
- 광고에 실린 기기 이름
- 신호 세기(RSSI)
- 블루투스 주소: 같은 세션 안에서 같은 기기를 구분하는 데만 쓰고 화면과 기록에는 세션 안 번호(#12)만 나온다.

읽지 않는 것
- 제조사 데이터와 서비스 데이터의 나머지 내용. 앱은 앞 2바이트 이후를 해석하지 않는다.
- 기기와의 연결, 페어링, GATT 조회. 코드에 연결 호출이 없다. `app/lib/src/scan/ble_scanner.dart`
- 폰의 위치 좌표. Android 12 이상은 `BLUETOOTH_SCAN`을 `neverForLocation`으로 선언했다. Android 11 이하는 OS가 BLE 스캔에 위치 권한을 요구해서 그 버전에서만 요청하고(`maxSdkVersion=30`) 위치 값은 읽지 않는다.

## 2. 저장과 전송을 하지 않는 이유와 방법

- 인터넷 권한을 매니페스트에서 제거했다(`tools:node="remove"`). 빌드된 APK의 권한 목록을 `aapt2 dump badging`으로 확인했다(2026-10-25).
- 감독 데이터는 `ExamSession` 객체 메모리에만 있다. 감독 기록 화면을 나가면 객체가 사라진다. 디스크에 쓰지 않는다.
- 폰에 저장하는 값은 약관 동의 여부, 동의한 약관 버전, 동의 시각뿐이다. `app/lib/src/ui/consent_screen.dart`
- 내보내기(이미지, 세부 로그)는 사용자가 누를 때만 임시 폴더에 파일을 만들어 공유 시트로 넘긴다. 블루투스 주소는 넣지 않는다. 이 동작은 테스트로 확인한다(`보고서에 기기 주소(MAC)가 들어가지 않음`).
- 내보내는 기록에는 광고된 기기 이름도 넣지 않는다(2026-10-25 추가). "홍길동의 AirPods"처럼 사람 이름이 들어갈 수 있어서다. 기록에는 시그니처 분류나 제조사만 쓴다(`TrackedDevice.exportLabel`). 감독 중 화면에는 이름이 보인다.
- 공유용 임시 파일은 다음 내보내기 직전, 감독 기록 화면을 나갈 때, 앱을 켤 때 지운다(`cleanExportFiles`). 공유 직후 바로 지우면 파일을 나중에 읽는 앱에서 공유가 깨질 수 있어서 이 시점으로 정했다.
- Android 백업을 껐다(`android:allowBackup="false"`).

이유: 학생의 기기 정보를 모으지 않으면 유출될 것도 없다. 감독에 필요한 것은 "지금 이 교실에 의심 신호가 있는가"이고, 장기 보관이나 서버 집계는 필요 없다.

## 3. 판단 규칙

- AI 안경 의심(빨강): 제조사 ID, 서비스 UUID, 기기 이름이 `app/assets/signatures.json`의 시그니처와 일치할 때. 시그니처는 코드가 아닌 데이터 파일에 있다.
- 새 기기(노랑): 교실 기기 확인 시간이 끝난 뒤 처음 잡힌 기기 가운데, 확인 시간 동안 같은 모양(제조사 ID, 서비스 UUID, 이름 조합)의 기기가 없었고, 3번 이상 잡혔고, 신호가 설정한 범위보다 셀 때.
- 블루투스 주소는 주기적으로 바뀌므로(MAC 랜덤화) 주소만으로 새 기기를 판단하지 않는다.

## 4. 알려진 오탐과 한계

- Meta 제조사 ID(0x01AB, 0x058E)는 메타 퀘스트 같은 VR 기기에도 쓰인다.
- Jieli 칩 ID(0x05D6)는 같은 칩을 쓰는 저가 이어폰과 스피커에서도 나올 수 있다.
- 신호 세기는 몸과 책상에 가려 크게 흔들린다. 교실 단위까지는 의미가 있지만 좌석은 특정할 수 없다.
- 블루투스를 끈 채 녹화만 하는 기기는 잡을 수 없다.
- Android는 화면이 꺼지면 필터 없는 스캔을 멈춘다. 그래서 감독 중에는 화면을 켜 둔다.
- 아직 실물 신호를 확보하지 못한 제품: 이븐리얼리티스 G1/G2, 로키드, 샤오미, 알리바바 Quark, 삼성 갤럭시 글래스.

이 한계는 앱 안 고지, 동의 화면, 이용약관, 사용 지침에 같은 내용으로 적는다.
